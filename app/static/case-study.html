THE PROBLEM

The PDF is only the beginning.

A team receives contracts with names, dates, values and payment conditions buried in text. Moving those values into a spreadsheet is useful only if missing information, contradictory clauses, and extraction mistakes remain visible. This project reconstructs that workflow using synthetic data.

Eight authored fictional contracts cover labelled English and Portuguese, narrative wording, wrapped clauses, ambiguous dates and conflicting fields. Answers are specified separately from the extractor. This small corpus is visible during development; it is not an unseen test set.

OPERATING THE WORKFLOW

The useful details
are in the recovery.

Processing failures and quality findings have different destinations. A document can finish processing successfully and still require a human decision.

Inspect runs & lineage

Idempotency with configuration identity

Same PDF and configuration: reuse the result. Change the model, prompt or policy fingerprint: create a separate versioned run.

Recoverable, bounded attempts

A worker claims a five-minute lease. Expired claims can be resumed, and stale workers cannot commit over a new owner. Each run allows at most three attempts.

Atomic output and quality quarantine

Fields, evidence, findings and completion state commit in one transaction. Records requiring review remain outside the accepted-data view.

Provider usage stays explicit

The optional OpenAI adapter records reported token usage. No paid extraction has been verified here; provider cost and real-world accuracy remain unmeasured.

Delivery

CLI commands, SQL queries, fictional fixtures, automated tests, evaluation artifacts and a review interface.

Scope of this implementation

Local portfolio demonstration. Batch processing stores PDFs, extracted text and results in a local SQLite database. Single-document review remains transient. There is no OCR, authentication, legal advice or public deployment. Live LLM quality, provider cost, production load and hostile-PDF isolation have not been verified.
