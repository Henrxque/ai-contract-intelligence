THE EXTRACTION PIPELINE

      
Inspect the whole story.

      

        
Read the PDF

        

          Extract selectable text page by page. Encrypted, unreadable and
          scanned-only files get actionable errors. OCR is not included.
        

        
Structure the fields

        

          Local rules read supported labels. Optional OpenAI extraction uses a
          typed schema for varied wording. The selected mode is always shown.
        

        
Check the evidence

        

          Validate required values, dates, amounts, date ordering, and whether
          source quotes appear on their claimed page. These checks do not
          establish legal validity or guarantee completeness.
        

        
Review and export

        

          Inspect missing, uncertain and invalid fields. Export JSON, CSV or
          Excel with evidence and review statuses preserved.
        

      

      

        Single-document review keeps its result in browser memory until refresh.
        The separate batch pipeline stores PDFs and results in local SQLite. LLM
        mode sends extracted text to OpenAI; provider retention policies apply.
        Do not use confidential contracts in a public portfolio demo.
