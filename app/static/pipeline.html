QUERY THE DELIVERY

Accepted data has a clear boundary.

accepted_contract_fields contains supported fields from contracts whose checks passed. Contracts requiring review remain in quality_quarantine. Failed processing attempts do not create partial normalized output. 

SELECT field_key, value, status
FROM accepted_contract_fields
WHERE field_key IN (
  'party_a', 'party_b', 'total_value'
);

SELECT field_key, value, status
FROM quality_quarantine
WHERE status != 'supported';

Local data handling

Batch mode saves original PDF bytes, raw text, extractor output, normalized fields, evidence and run history to the configured local SQLite database. It is excluded from Git. Records remain until you remove the database and its WAL/SHM files with the server stopped. Keep confidential data out of shared demonstrations. Use single-document review for transient processing.
